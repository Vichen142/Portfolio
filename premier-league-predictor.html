⚽ Premier League Monte Carlo Champion Predictor & Odds Engine

📌 System Overview

The Premier League Season Simulator & Odds Radar is a full-stack, machine learning–powered forecasting web application designed to project league outcomes dynamically across the 38-match calendar.

Rather than relying on static pre-season predictions, the system couples a trained Random Forest Classifier with a 1,000-iteration Monte Carlo simulation engine. As users ingest real matchday scores, the application locks in actual earned points, recalculates head-to-head probabilities for all remaining unplayed fixtures, and re-evaluates title odds, Champions League qualification (Top 4) probabilities, and relegation risks in real time.

⚙️ Core Architecture & Features

  • 3-Way Match Outcome Engine: A Random Forest classifier paired with dynamic Elo ratings and rolling team form metrics (goals scored, shots on target, form points) predicts Home Win, Draw, and Away Win probabilities.
  • Monte Carlo Simulation Core: Simulates the remaining fixture calendar 1,000 times per update via vectorized NumPy execution. Ingested matches are removed from future simulations to ground projections in actual standings.
  • Reactive Dual-View Dashboard: Visual glassmorphism cards track title favorites alongside a 20-team projection table (Title %, UCL %, Relegation %, Projected PTS).
  • Dynamic Match Ingestion & State Persistence: Complete matchday score recording (GW 1–38) with rollback capabilities, serialized directly to structured JSON state.
